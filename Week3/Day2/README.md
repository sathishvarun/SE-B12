# Week 3 – Day 2: Install and Verify n8n

## 1. Objective
The objective of this assignment was to understand n8n, set up the environment, create a basic workflow, and verify that the workflow executes successfully.

## 2. Tools Used
- **n8n Cloud:** Workflow automation platform
- **Web Browser:** To access the n8n editor
- **GitHub:** To document and submit the assignment

## 3. Step-by-Step Implementation

### Step 1: Access n8n
I accessed my n8n cloud instance using my one-month subscription.

**n8n Workflow:** [Open My Workflow](https://n8n-2fqi.srv2061895.hstgr.cloud/workflow/5EoBis0jZRwcBQJR?new=true)

### Step 2: Open the Workflow Editor
I opened the n8n editor in my browser and explored the workflow canvas, where nodes can be connected to automate tasks.

### Step 3: Create a New Workflow
I created a basic workflow to understand how n8n workflows operate.

### Step 4: Add a Manual Trigger Node
I added the **Manual Trigger** node.

**Purpose:** This node allows me to start the workflow manually by clicking the **Execute Workflow** button.

### Step 5: Add an Edit Fields Node
I added the **Edit Fields** node to the workflow.

**Purpose:** This node allows me to create or modify data fields that can be used by subsequent workflow steps.

### Step 6: Connect the Nodes
I connected the Manual Trigger node to the Edit Fields node.

**Workflow Structure:**

`Manual Trigger → Edit Fields`

### Step 7: Execute the Workflow
I clicked **Execute Workflow** in the editor to run the workflow.

### Step 8: Verify Successful Execution
I checked the execution result in the n8n editor and confirmed that the workflow ran successfully.

### Step 9: Save the Workflow
I saved the workflow in my n8n environment so that I could access it again.

## 4. Key Learnings

- Learned how nodes process and modify data.
- Practised connecting nodes and executing a workflow.
- Understood the difference between cloud-hosted n8n and local installation.
