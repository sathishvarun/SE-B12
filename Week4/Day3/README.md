# Week 4 · Day 3 — CrewAI Travel Planner Agent

## Project Overview

This project builds a simple AI-powered travel planner using Python and CrewAI. The user enters a city, and a Travel Planner agent recommends exactly three places to visit, with a short description and a practical visiting tip for each place.

## Technologies Used

- Python 3.12
- CrewAI
- OpenAI API
- `python-dotenv` for loading environment variables

## Project Structure

```text
travel-planner/
├── .env                 # Stores the API key and model name (do not commit)
├── .gitignore           # Excludes secrets and local environment files
├── travel_planner.py    # Main CrewAI application
└── venv312/             # Python virtual environment (do not commit)
```

## Prerequisites

- Python 3.12 installed
- An OpenAI API key with API access and available billing/credits
- VS Code or another Python editor

## Application Code

Create `travel_planner.py` and add the following code:

```python
import os
from dotenv import load_dotenv
from crewai import Agent, Task, Crew

# Load environment variables from .env
load_dotenv()

api_key = os.getenv("OPENAI_API_KEY")
model_name = os.getenv("MODEL", "openai/gpt-4o-mini")

if not api_key or api_key == "your_actual_api_key_here":
    raise ValueError(
        "Please add your actual OpenAI API key to the .env file."
    )

# Ask the user for a city
city = input("Which city would you like to explore? ").strip()

if not city:
    raise ValueError("Please enter a city name.")

# Create the Travel Planner agent
planner = Agent(
    role="Travel Planner",
    goal=(
        "Recommend exactly three interesting places to visit "
        "in the city selected by the user."
    ),
    backstory=(
        "You are an experienced travel planner who helps first-time "
        "visitors discover local attractions. Your audience wants "
        "short, practical travel recommendations rather than a "
        "long travel essay."
    ),
    llm=model_name,
    verbose=True
)

# Create one task
task = Task(
    description=(
        "Recommend exactly 3 places to visit in {city}. "
        "For each place, provide the attraction name, a short "
        "description, and one practical visiting tip."
    ),
    expected_output=(
        "Exactly 3 numbered recommendations. Each recommendation "
        "must include the place name, a concise description, "
        "and one practical visiting tip. No introduction or conclusion."
    ),
    agent=planner
)

# Create the crew
crew = Crew(
    agents=[planner],
    tasks=[task],
    verbose=True
)

# Execute the crew
result = crew.kickoff(inputs={"city": city})

# Print the result
print("\n===== TRAVEL PLANNER RESULTS =====\n")
print(result)
```

## Run the Application

From the project directory, with the virtual environment activated, run:

```bash
python travel_planner.py
```

When prompted, enter a city, for example:

```text
Which city would you like to explore? Jaipur
```

The agent should return exactly three numbered recommendations. Each should include the place name, a concise description, and a practical visiting tip. Results are generated by the model and may vary between runs.

Test the application with at least three cities, such as Jaipur, Chennai, and Dubai.

## Troubleshooting

- **`can't open file ... travel_planner.py`:** Make sure the file is saved as `travel_planner.py` inside the `travel-planner` project folder. Check with `pwd` and `ls -la`.
- **Package installation / `tiktoken` build error:** Confirm Python 3.12 is active using `python --version`, then retry the dependency installation in the activated virtual environment. If the error persists, review the complete installation log.
- **API key error:** Check that `.env` is in the project root and that `OPENAI_API_KEY` contains your valid key.
- **Model/API error:** Check that your OpenAI API account can access the selected model and has API billing/credits available.
